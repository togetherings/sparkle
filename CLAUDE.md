# Notes for working on this repository

- Sparkle is a Scored Game made with EduGame Kit (github.com/togetherings/edugame-kit): its docs
  (MAKING_GAMES.md, HELPER.md, SCORING.md, LANGUAGES.md) describe edugame.json, the save helper and
  the workflows. It reaches Kolibri through Kolibri Studio (channels); Kolibri Games
  (github.com/togetherings/kolibri-games) shows its scoreboards, and can also run it on its games page.
- `game/` is the game folder (`edugame check game`, `edugame build game`, `edugame preview game`).
  Keep everything in it relative and self-contained: no network, no build step, plain ES5-style
  JavaScript that runs on old tablets.
- Rules live in `game/logic.js` (no page code, tested with `node --test tests/*.test.js`);
  screens and EduGame calls live in `game/game.js`. Every word the game shows is in
  `game/lang/<code>.json`.
- `game/words/<code>.json` (content loaded with `EduGame.load`) is generated by
  `tools/build_words.py`; change `tools/words/<code>/*.txt` and rebuild rather than editing it.
- Languages: English first, French the first added. Never add another language (translations,
  word lists, examples) without the owner's permission.
- Scoring: each language is a board (`"en"`, `"fr"`), so each has its own scoreboard. Each finished
  daily word reports that day's points (`finish({score})` on the language's board), with
  `counts: "total"`, so the scoreboard adds them up. Practice never calls start/finish.
- The save (`EduGame.save`, see logic.js) is small and bounded (SCORM's 4,096 characters): the latest
  daily word and the stats for each place ("free" or "c<challenge id>") and language, at most 6.
  Sparkle saves after every guess (Kolibri Learn drops saves made as the learner leaves).
- Changing how daily words are picked (logic.dailyWord) or the answer order changes every
  learner's word for the day; only do it in a new version, and say so in the CHANGELOG.
- Bump `version` in game/edugame.json and add a CHANGELOG entry before a release.
- Tests: `node --test tests/*.test.js`, `python3 tests/browser_test.py` (the kit's test page),
  `python3 tests/games_page_test.py` (needs kolibri-games), `edugame kolibri-test game` (a real
  Kolibri; CI runs it in the Kit job).
- Writing style for anything users see: plain words, sentence case, active voice.
