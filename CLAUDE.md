# Notes for working on this repository

- Sparkle is a Scored Game (manifest type "scored") for Kolibri Games (github.com/togetherings/kolibri-games),
  played on its games page for now; it will be reworked with EduGame Kit (github.com/togetherings/edugame-kit). Its
  game format and SDK are documented there in docs/GAME_FORMAT.md.
- `game/` is exactly what goes in the zip. Keep everything in it relative and self-contained:
  no network, no build step, plain ES5-style JavaScript that runs on old tablets.
- Rules live in `game/logic.js` (no page code, tested with `node --test tests/*.test.js`);
  screens and SDK calls live in `game/game.js`.
- `game/words.js` is generated by `tools/build_words.py`; change `tools/words/*.txt` and rebuild
  rather than editing it.
- Scoring: each finished daily word reports the learner's running total of points as the score,
  with `counts: "best"`, so the scoreboard shows totals. Practice never calls KG.start/finish.
  Saved data (KG.setState) keeps days per scope ("free" or "c<challenge id>").
- Changing how daily words are picked (logic.dailyWord) or the answer order changes every
  learner's word for the day; only do it in a new version, and say so in the CHANGELOG.
- Bump `version` in game/kolibri-game.json and add a CHANGELOG entry before a release.
- Writing style for anything users see: plain words, sentence case, active voice.
